# Workflow: Phase F — AI Gateway, Web Workspace, and Runner

## Goal

Add BYOK provider POC, Model Router skeleton, web workspace plan, remote runner model, and MVP demo flow.

## Steps

1. Define AI provider abstraction.
2. Add Model Router capability/cost/context/privacy criteria.
3. Design BYOK provider flow and secret storage boundary.
4. Plan web workspace options: File System Access API, OPFS, git-backed workspace.
5. Define Remote Runner job and log streaming models.
6. Define dev server preview proxy and remote PTY model.
7. Plan PR-based web agent workflow.
8. Validate MVP demo flow end-to-end.

## Success Criteria

- BYOK/OAuth remains primary access model.
- Web agent execution is sandboxed or runner-backed.
- Secret and token handling is safe by design.
